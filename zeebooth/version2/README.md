# Zeebooth

A responsive browser photobooth prototype with:
- Home / Photos / Riwayat
- Camera capture
- 1–4 photo sessions
- Aspect-ratio-aware camera preview and canvas capture
- Countdown and shutter sound
- One global gesture toggle
- ✌️ blur gesture
- 🖐️ flower gesture
- 🫶 heart gesture
- Editor / frame / background selection
- LocalStorage photo library and history
- Responsive soft-glass UI

## Notes
- Gesture detection uses MediaPipe Hands loaded from CDN in `js/gesture.js`.
- Camera access normally requires HTTPS (or localhost).
- The included background SVGs are aesthetic placeholders. Replace them with real edited photo-scene backgrounds later.
- Audio files are generated by Web Audio in `app.js`, so there are no binary sound assets required.
